# Life Planner AI · 视觉与动效规范（v2.2 · Warm Journal）

本文件是 UI 的唯一事实来源。新增硬编码色值 / 圆角 / 动画时长视为缺陷。

## 0. 为什么从 2.1 改成 2.2

2.1 的「紫青极光 + 玻璃卡片 + 星芒图标 + 悬浮胶囊」有两个问题，用户反馈很直接：

1. **太像 AI 生成器**：高饱和渐变、发光圆斑、闪光图标堆在一起，会让私人生活工具像营销页；
2. **层次混乱**：玻璃叠层 + 悬浮导航让滚动内容从导航两侧露出来，容易被读成"页面重叠"。

2.2 的方向是**暖色手账 / 安静的私人工具**：实色面、细边、单一强调色、系统级底部导航。
AI 只在"你主动发起"时出现，界面上不再到处写 AI。

## 1. 颜色令牌（LpColors）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| Background | #121110 | 暖调近黑页面底 |
| Surface | #1B1917 | 卡片 / 输入面 |
| SurfaceHigh | #24211E | 浮起面：弹窗、底部栏 |
| SurfaceVariant | #2C2824 | 次级底、输入框、进度轨道 |
| Border | #1FFFFFFF | 白 12% 细边 / 分割线 |
| BorderStrong | #2EFFFFFF | 聚焦边 |
| Accent | #D98E63 | 陶土色：唯一强调色（关键动作、选中） |
| AccentDim | #C4764B | 强调色深一档 |
| AccentAlt | #8FAE8B | 鼠尾草绿：次级正向 |
| Positive | #9DBF9E | 完成 |
| Danger | #D97A6C | 风险 |
| Warning | #D9A441 | 注意 |
| Info | #8FA8B8 | 说明 |

规则：
- 不用渐变做装饰；LpGradients 只是兼容层（Brand 近似实色、Hero 透明）。
- 不放发光圆斑 / 光晕；背景是纯暖黑 + 极轻纵向过渡（LpBackground）。
- 状态色只表达状态，不承担品牌识别。

## 2. 字体（LpTypography）

| 样式 | 规格 | 用途 |
| --- | --- | --- |
| displaySmall | 27 / 35 SemiBold | 首页问候 |
| headlineMedium | 21 / 29 SemiBold | 页面标题 |
| titleLarge | 18 / 26 SemiBold | 区块标题 |
| titleMedium | 15.5 / 23 Medium | 卡片标题、按钮 |
| bodyLarge | 15 / 23 | 正文 |
| bodyMedium | 14 / 21 | 次级正文 |
| bodySmall | 12.5 / 19 | 说明 |
| labelSmall | 11 / 15 Medium | 标签、辅助信息 |

## 3. 形状与间距

- 卡片 16dp；内层 12dp；按钮 12dp；输入框 12dp；徽章 999dp。
- 页面左右留白 20dp；区块间距 24dp；卡片内边距 16dp；卡片间距 12dp。
- 底部导航是**贴底整条栏**（高 58dp + 导航栏 insets + 1px 顶分割线），不是悬浮胶囊。

## 4. 动效

- 页面切换：210ms 淡入 + 8dp 上移；退出 140ms。
- 内容淡入 180ms；进度数字 500ms；按钮不做缩放；列表错峰最多 6 项、每项 30ms、位移 6dp。
- 禁止：整屏 loading 替换已有内容；大幅位移/弹跳；发光呼吸动画。

## 5. 首页结构

1. 日期（labelSmall）+ 问候（displaySmall）；右侧档案 / 设置图标按钮（40dp，无底色）。
2. **[仅档案空时] 建档访谈卡**：「先认识一下你」+ 一句说明 + 「开始访谈 →」。
3. **一句话记录条**：整条可点，右侧小「＋」；文案「记一句今天，或说说接下来想做什么…」。
4. 概览：一行三个数字（连续记录 / 完成率 / 今日任务），中间用 1px 分隔线，不用三张卡。
5. 今日任务（勾选 + 进度环）。
6. 每日一句（引文 + 作者 + 生活/学习/工作提醒，可收起）。
7. 今日计划（生成按钮 + 结果确认；不再叫「AI 今日计划」）。
8. 趋势（学习 / 睡眠，7/30 天）。
9. 生活缺口。
- 数据加载失败才显示错误条；有旧内容时静默刷新，不闪 loading。
- 首页不放 Hero 大卡、不放「AI」徽章、不放星芒图标。

## 6. AI 建档访谈（全屏页）

- 入口：首页访谈卡（档案未完成时）、档案页「AI 访谈建档」。
- 页面自带 header（返回 / 认识你 / 重新开始），不显示底部导航。
- 对话：AI 左、用户右，无头像；「对方正在输入…」用淡气泡，不整块 loading。
- 进度：「已了解 X / 7 个话题」+ 3dp 细条。
- 覆盖话题：工作/行业、年龄性别、收入、当前状态与困扰、想达到的状态、达成方式、未来想成为的人、现实约束。
- 结束：总结卡（已了解信息、愿景、约束、最多 3 个建议目标可勾选）→「保存到我的档案」；写入 Profile + Goal，**不写任务**。
- 未配置 Key：说明 + 去设置；危机：只展示关怀与热线，不保存。

## 7. 弹窗（一句话整理）

- 使用 ModalBottomSheet，跳过半展开；内容区滚动，输入框随键盘上移。
- 先展示 AI 草稿（记录 / 任务 / 目标，默认全选），确认后才落库。
- 没有「AI 整理失败就用模板填」这种降级：失败显示真实错误。

## 8. 布局与 insets 规则（避免重叠）

- 根 Scaffold 统一处理状态栏 / 导航栏 / 输入法：页面**不要**再调用 statusBarsPadding / navigationBarsPadding。
- 底部导航只由 root 提供，页面不要自己加底部浮层或固定底栏。
- 弹窗 / 图表 / 长列表必须在内容区内部滚动，不越过 Scaffold 的 padding。
- 任意固定高度容器（按钮 46dp、导航 58dp）禁止放多行文本，避免字体放大时相互覆盖。
- 首页内容末尾留 24dp，确保最后一张卡片与底部栏之间有呼吸。

## 9. 禁止项

- 空状态伪装成有数据；本地模板冒充 AI。
- 页面里写死 Color(0x...)（遮罩除外）。
- 新增第三方 UI 依赖。
