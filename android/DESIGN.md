# Life Planner AI · 视觉与动效规范（v2.1）

本文件是 UI 重构的唯一事实来源。所有页面、组件、动效都必须遵守；
新增硬编码色值 / 圆角 / 动画时长视为缺陷。

## 1. 设计方向

**Aurora Ink（极光墨）**：深色打底 + 极光渐变点缀 + 玻璃拟态卡片。
目标是「安静、通透、有呼吸感」，而不是黑色 + 荧光绿的高压感。

- 背景：近黑偏蓝的墨色，叠两团极低透明度的径向光晕（紫 + 青）。
- 卡片：比背景略亮的半透明面 + 1px 柔边 + 大圆角，不用重阴影。
- 强调色：紫（主）→ 青（副）的渐变，只在关键动作、进度、选中态出现。
- 信息层级靠字号、字重、透明度区分，不靠描边和分割线。
- 中文排版优先：正文行高 1.5~1.6，标题字重 SemiBold/Bold，
  数字用 tabular 感觉（等宽数字用 FontFeatureSettings 可选）。

## 2. 颜色令牌（`ui/theme/Theme.kt` · `LpColors`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `Background` | `#07080C` | 页面底色 |
| `Surface` | `#12141C` | 卡片默认面 |
| `SurfaceHigh` | `#191D28` | 浮起面 / BottomSheet / 底部导航 |
| `SurfaceVariant` | `#222838` | 次级底、进度轨道、输入框底 |
| `Border` | `#1FFFFFFF` (白 12%) | 卡片描边、分割线 |
| `BorderStrong` | `#33FFFFFF` (白 20%) | 聚焦/强调描边 |
| `Accent` | `#8B7BFF` | 品牌主色（紫） |
| `AccentDim` | `#6D5CFF` | 主色深一档 |
| `AccentAlt` | `#2DD4BF` | 副色（青） |
| `Positive` | `#34D399` | 完成 / 正向 |
| `Danger` | `#FB7185` | 风险 / 危险 |
| `Warning` | `#FBBF24` | 注意 |
| `Info` | `#60A5FA` | 说明信息 |
| `TextPrimary` | `#F5F7FB` | 主文字 |
| `TextSecondary` | `#C3C9D9` | 次文字 |
| `TextMuted` | `#8A93A8` | 弱文字 |

渐变（`LpGradients`）：
- `Brand`：135°，`#8B7BFF` → `#2DD4BF`（按钮、进度、选中指示）
- `Warm`：135°，`#FFB86B` → `#FB7185`（连续记录、Streak 等温度感元素）
- `Hero`：160°，`#8B7BFF`(22%) → `#2DD4BF`(8%)（首页 Hero 卡背景）
- `Glass`：180°，`#FFFFFF`(8%) → `#FFFFFF`(2%)（玻璃卡面）

**兼容要求**：`LpColors` 现有字段必须全部保留（其余 6 个页面仍在用），
只允许调整色值 + 新增字段，不允许删除或改名。

| 样式 | 规格 | 用途 |

| `headlineMedium` | 24sp / Bold | 页面大标题、Sheet 标题 |
| `titleLarge` | 20sp / SemiBold | 区块大标题、卡片主数字 |
| `titleMedium` | 16sp / SemiBold | 卡片标题、按钮 |

## 4. 形状与间距

- 卡片圆角 `20dp`，内层小卡 `16dp`，输入框 `16dp`，按钮 `16dp`，Chip `999dp`。
- BottomSheet 顶部圆角 `28dp`，遮罩 `#CC000000`。
- 页面左右留白 `20dp`；区块间距 `24dp`；卡片内边距 `18dp`；卡片间 `12dp`。
- 底部导航：悬浮胶囊，左右各 16dp，距底部 12dp，高 64dp，圆角 28dp。

## 5. 动效

- 页面切换：`fadeIn 260ms` + `slideInVertically(16dp)`；退出 `fadeOut 160ms`。
- 数据加载完成：内容淡入 + 轻微上移（220ms），不要整屏闪烁。
- 卡片按压：缩放到 `0.97`（spring, Medium）。
- 进度/统计数字：`animateFloatAsState` 600ms。
- AI 处理中：骨架屏或内联进度，**禁止**把已有内容整块替换成 loading。
- 选中态切换（底部导航、Tab、Chip）：指示器 220ms 平滑移动。
- 列表项进入：最多前 8 项做 40ms 错峰淡入，超过则一次性显示（性能）。

## 6. 首页结构（Home）

自上而下：
1. 问候行：左「晚上好」+ 日期副标题；右「档案」「设置」两个圆形图标按钮。
2. **AI 一句话整理入口（Hero）**：渐变描边大卡片，一行提示
   「说一句话，AI 帮你整理今天」+ 右侧渐变发送按钮；点击打开弹窗。
3. 每日一句卡片：励志短语 + 作者 + 生活/学习/工作三条提醒（可折叠）。
4. 今日概览：连续记录 / 完成率 / 今日任务数（三枚玻璃小卡）。
5. 今日任务（保留原有勾选逻辑）。
6. AI 今日计划（原有逻辑，视觉降级到中段）。
7. 趋势图（7/30 天）与生活缺口。
- 滚动时顶部可渐显一条细分割/模糊条（可选），不做折叠大标题，避免状态复杂。

## 7. AI 一句话整理弹窗（Capture Sheet）

- `ModalBottomSheet`，跳过半展开，顶部标题「AI 一句话整理」，副标题说明用法。
- 输入区：多行输入框（默认 4 行），占位示例：
  「今天学了 1 小时英语，晚上跑了 3 公里，心情不错；明天想把论文初稿写完」
- 快捷示例 Chip（3 个）：今日复盘 / 明天的安排 / 随便问问。
- 主按钮「让 AI 整理」；未配置 Key 时给出「去设置」入口。
- 结果区（AI 返回后）：
  1. AI 回应（reply，可折叠）
  2. 整理出的记录：胶囊标签（学习 60 分钟 / 睡眠 23:30-07:00 / 心情 4/5 …）
  3. 今日任务：可勾选列表（默认全选）
  4. 新目标：可勾选列表（默认全选）
  5. 底部：主按钮「保存到我的计划」+ 次按钮「重新整理」
- 保存成功：轻震动反馈 + Snackbar「已整理并保存：3 项任务」+ 关闭弹窗 + 首页刷新。
- 空输入、超长输入（>2000 字）、请求中重复点击都要有明确禁用态。

## 8. 每日推送

- 早间（默认 07:30）：问候 + 今日主题（引用每日一句）+ 生活/学习/工作各一条提醒。
- 晚间（默认 21:30）：今日复盘提醒 + 一句鼓励（引用每日一句）。
- 文案全部来自 `core/daily/DailyQuotes`，离线可用、按天轮换。
- 通知渠道 `daily_push`（重要性 DEFAULT），小图标用单色 `ic_stat_life`。
- 点击通知进入 App：早间进首页，晚间进复盘页（用 Intent extra 指定）。
- 用户可在设置页开关、改时间、发送测试通知；改完立即重排下一次闹钟。

## 9. 禁止项

- 不允许空状态伪装成有数据；不允许用本地模板假装 AI 结果。
- 不允许在页面里写死 `Color(0x...)`（除极少数遮罩），一律取 `LpColors`。
- 不允许把网络请求放在主线程或使用 `GlobalScope`。
- 不允许新增第三方 UI 依赖（保持当前依赖集，除必要且已说明的库）。
