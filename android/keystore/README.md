# 自用签名密钥（重要）

`lifeplanner.jks` 是这个项目**自用分发**的稳定签名密钥，CI 与本机构建都用它签名。

为什么必须提交到仓库：
- Android 只允许"签名相同"的 APK 覆盖安装；
- 如果每次 CI 都用临时 debug keystore，用户安装新版本时会报"应用未安装"，
  自动更新就形同虚设。

安全边界：
- 这是**个人自用**密钥（别名 `lifeplanner`，密码在 `app/build.gradle` 中），
  不是应用商店上架密钥；拥有仓库写权限的人都能签出可覆盖安装的包，这是已知取舍。
- 如果将来要公开分发或上架，请：
  1. 生成新的私钥并妥善保管；
  2. 通过 CI Secrets 注入（`ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD` 等），
     而不是继续把密钥放在仓库里。
- 更换签名后，老用户需要卸载重装一次（数据可用"设置 → 导出备份"迁移）。
